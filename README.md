🌟 Featured Projects

🛰️ TerraGuard AI — Landslide Risk Monitoring & Early Warning System
`Python` `XGBoost` `Rasterio` `FastAPI` `Next.js` `React` `Firebase` `GIS` `Remote Sensing`
XGBoost-based landslide susceptibility model using terrain, satellite, and historical landslide data to flag high-risk zones across Northeast India.
Processed 30m DEM and Resourcesat-2 LISS-3 satellite raster data with Rasterio to derive elevation, slope, aspect, hillshade, and spectral-change features.
Spatially validated ML pipeline with hard-negative sampling to reduce geographic data leakage and improve generalization.
FastAPI backend serving coordinate-based terrain analysis and risk predictions via REST APIs.
Next.js + React Leaflet dashboard with interactive terrain, risk, and satellite-change overlays; Firebase auth for secure access.

🛒 ShopHub — LLM-Powered Retail Chatbot
`React` `Node.js` `TypeScript` `LangChain` `LangGraph` `GPT-4.1-mini` `MongoDB Atlas` `Docker` `AWS EC2`
Agentic customer support chatbot for a furniture/retail platform — <2s average latency across 100+ concurrent sessions.
LangChain + LangGraph agentic backend with MongoDB Atlas vector search (1536-dim embeddings) and conversation checkpointing.
GitHub Actions CI/CD for automated builds and zero-downtime redeployment on AWS EC2; REST API at <100ms p95 latency.

🌿 PlantGuard — Plant Disease Detection
`Python` `TensorFlow` `CNN` `Streamlit`
CNN trained on 10,849 labelled leaf images across 38 disease classes — 91% test accuracy, <2s inference time (+31pp over baseline).
Deployed via an interactive Streamlit app with drag-and-drop image upload.
